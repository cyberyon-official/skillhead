# 0001 — Record architecture decisions

Status: Accepted

## Context

Agents and humans settle the same questions several times when the
previous answer is written nowhere.

## Decision

Every architecture decision is written in `docs/adr/`, one file per
decision, in the format of `0000-template.md`, and added to the index.

## Consequences

Before deciding, read the index. Going back on a decision takes a new
decision that supersedes it.
